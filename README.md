# satoshilevels
App summarizing valuation, momentum, on-chain and sentiment data for better buying and selling of Sats

Buy levels and buy-signal scores for Bitcoin, Ethereum and Solana, as a web app you can add to your phone's home screen.

## Use it
Open the GitHub Pages address of this repository:
- **iPhone (Safari):** Share → Add to Home Screen.
- **Android (Chrome):** ⋮ menu → Install app.

Prices and data are fetched directly by your browser from public sources (Kraken, Binance, CoinGecko, Coin Metrics, DefiLlama and others). Your settings, alerts and saved data stay in your own browser.

## Files
- `index.html`: the whole app
- `manifest.webmanifest`, `icons/`: name, icon and full-screen mode when installed
- `sw.js`: keeps the app available offline

This is a decision aid, not financial advice.
